# 資產再平衡工具

一個以瀏覽器執行的台股資產再平衡工具，提供持股管理、交易紀錄、CSV 匯入、目標配置、Beta 與高低點水位分析。

## 使用方式

本專案是靜態網站，不需要編譯。可直接開啟 `index.html`，或在專案目錄啟動本機伺服器：

```bash
python3 -m http.server 8000
```

再開啟 <http://localhost:8000>。

## 外部服務

- Fugle：取得即時報價，需要在設定頁輸入 API Key。
- FinMind：取得歷史價格與高低點，需要在設定頁輸入 Token。
- Chart.js 與 Tailwind CSS：由 CDN 載入。

API 金鑰只應在個人裝置使用。備份檔不會包含 API 金鑰，請勿把金鑰提交到 Git 或分享給他人。

## 資料與備份

持股、交易紀錄與設定目前儲存在瀏覽器的 `localStorage`。清除瀏覽器資料、換裝置或使用無痕模式都可能造成資料遺失，請定期使用「匯出備份」。

匯入備份會覆蓋目前的持股與設定；API 金鑰會保留目前裝置上的值，不會從備份檔匯入。

## 費用規則

- 買賣手續費：0.1425% × 2.8 折，最低 1 元。
- 總覽中的「含交易成本均價／付出成本」會以買入實付成本，加上目前現價賣出預估的手續費與交易稅計算；賣出費用會隨現價更新，不會重複累加。
- 賣出證交稅：一般股票 0.3%，ETF 0.1%。
- 實際費率請依券商與當時法規為準。

本工具只提供計算與紀錄功能，不構成投資建議。
